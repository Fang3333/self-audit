处置清单

手机号

必做工信部「一证通查」——查名下手机卡

官方免费渠道，能查出你身份证下到底有几张手机卡。多出来的就是被冒名办的，可以直接申请注销。这是唯一能查全的官方途径。

微信/支付宝搜小程序「一证通查」→ 移动电话卡查询 → 填姓名+身份证+手机号，24 小时内短信回复结果。网页版 hbjy.miit.gov.cn
必做工信部「一证通查 2.0」——查手机号注册了哪些互联网账号

同一个入口，能查你的手机号在微信、QQ、淘宝、支付宝、抖音、微博、美团、京东、快手、B站等 16 个平台注册了几个账号。查出陌生账号 = 你的号被人拿去注册过。

同一小程序 → 互联网账号查询 → 勾选要查的平台，48 小时内出结果
建议运营商号码标记查询

手机号被第三方标记成「骚扰」「诈骗」「外卖」会影响别人接你电话，也能反映号码被谁用过。

移动：中国移动 App → 我的 → 号码标识；联通/电信类似，或搜「码号服务推进组」公众号查
建议关闭各平台的「通过手机号找到我」

这是陌生人能拿你手机号反查到你账号的唯一通道。关掉之后别人拿号搜不到你，代价是熟人也不能靠手机号加你。

微信：设置 → 朋友权限 → 添加我的方式 → 关「手机号」
QQ：设置 → 隐私 → 发现我的方式 → 关「手机号」
微博：设置 → 隐私设置 → 关闭「允许通过手机号搜索到我」
抖音：设置 → 隐私设置 → 关闭「允许通过手机号找到我」
小红书：设置 → 隐私 → 关闭「允许通过手机号找到我」
建议微信朋友圈陌生人可见

默认「允许陌生人查看十条朋友圈」，等于把最近动态给所有能搜到你的人看。

微信：设置 → 朋友权限 → 朋友圈 → 关闭「允许陌生人查看十条朋友圈」

账号与密码

必做按重要性分级，别所有站一个密码

分级：邮箱 > 支付/银行 > 社交主号 > 论坛/工具站。邮箱是第一优先——它往往是所有其他账号的找回入口，邮箱被破等于全丢。

给邮箱和支付单独设强密码 + 开二次验证；低价值站点用一次性密码
必做开启二次验证（2FA）

密码泄露了还有第二道门。优先给：邮箱、微信、QQ、GitHub、Gitee、Apple ID、支付宝。

优先用 TOTP（Google Authenticator / 微软 Authenticator / 1Password），短信验证码次之（可被 SIM 劫持）
建议注销不用的老账号

暴露面 = 账号数 × 每个账号的信息量。十年不用的论坛号仍在泄露你的邮箱和历史发言。

本工具 B 级扫描出的站点，逐个判断是否还需要；不用的走「账号注销」流程（多数站在设置-账号-注销账号）

代码仓库

必做git 提交邮箱改成 noreply

每次 commit 都会把邮箱写进历史，公开仓库等于把邮箱挂出来，而且能被 GitHub 关联到你所有其他仓库。

git config --global user.email "<ID>+<用户名>@users.noreply.github.com"
GitHub 设置 → Emails → 勾选 Keep my email addresses private
建议扫一遍历史提交里的密钥

很多人把 .env、云厂商 AK/SK、数据库密码提交过一次然后删掉——历史里还在。

pip install gitleaks 后用 `gitleaks detect --source . -v`；或 trufflehog filesystem . --only-verified
建议检查个人资料字段

GitHub/Gitee 的 name、company、location、blog 四个字段最能定位到真人。

GitHub → Settings → Public profile；确认 location 不用写到区，company 不写真实单位

邮箱与凭据

必做查邮箱是否在已知拖库里

HaveIBeenPwned 收录了数百起公开数据泄露。邮箱命中说明密码哈希已外流，如果那个密码你还在别处用，必须立刻改。

https://haveibeenpwned.com 输入邮箱（网页免费）；国内可查 https://monitor.mozilla.org
建议用别名邮箱隔离注册

一个邮箱注册所有站，一旦某站被拖库，你的主邮箱就成了垃圾邮件和撞库的靶子。

Apple「隐藏我的邮箱」、SimpleLogin、Firefox Relay；国内可用 QQ 邮箱的「英文别名」或 Gmail 的 + 后缀（如 name+shop@gmail.com）
必做被拖库过就换密码，别只改一位

撞库工具会自动试 Password1 → Password2 这类变体，加个数字不算改。

换一个完全无关的新密码，并检查该站是否支持 2FA

线下与其他

建议快递单和外卖地址

快递面单上的姓名+手机号+门牌号是线下最常见的泄露源，丢件时整包信息一起走。

用驿站代收代替送上门；面单涂掉手机号中间四位再扔；外卖/快递 App 里用「隐私号码」功能
建议简历和求职平台

招聘网站默认公开简历，姓名、手机、邮箱、工作经历全在上面，且被爬虫抓走。

BOSS直聘/智联/前程无忧：简历设「仅投递企业可见」，关闭「允许猎头搜索」
可选搜索引擎里的自己

搜「姓名+手机号」「姓名+学校」看有没有被公开页面收录。

Google 有「关于你的个人信息」移除请求（需提供页面 URL）；百度用「百度搜索资源平台 → 删除快照」；学校/单位官网的公示名单可联系管理员下线
